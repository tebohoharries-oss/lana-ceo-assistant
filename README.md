# Lana Executive Suite

Build a modern, responsive "AI Workplace Productivity Assistant" web app tailored specifically for a Chief Executive Officer (CEO). 



Persona & System Architecture:

- User Role: Chief Executive Officer (CEO)

- AI Assistant Name: Lana

- Role & Tone: Executive-level assistant. Tone must be professional, direct, authoritative, highly organized, and concise.



Core Interface & Navigational Structure:

Design a clean corporate executive dashboard featuring a sidebar with Lana's name and branding, dark/light mode toggle, and 3 main functional tabs:



1. AI Chatbot Interface (Executive Assistant Chat):

   - Interactive chat window powered by "Lana".

   - Welcome message: "Good day, Chief Executive Officer. I am Lana, your executive AI assistant. How can I streamline your decision-making today?"

   - Quick-action buttons: "Draft Board Update", "Prep for Investor Call", "Review Strategic Risks".

   - Footer Disclaimer: "Lana is an AI assistant. Please verify financial, legal, and board-level decisions."



2. AI Task Planner & Scheduler (Executive Schedule Optimizer):

   - Form inputs: Executive Tasks, Strategic Priority Level (High/Board-Level, Medium/Operational, Low/Administrative), Estimated Duration, and Deadlines.

   - Output: An optimized daily schedule grouped into high-impact time blocks (e.g., Deep Work, Board/Leadership Meetings, Admin delegation), plus 2 high-level executive time-management tips.



3. AI Research Assistant (Briefing & Intelligence Generator):

   - Input field: Paste long reports, market analyses, or competitor data.

   - Output: Generates a clean "Executive Briefing" structured strictly into:

     1. Executive Summary (2 sentences max)

     2. Core Strategic Insights (3 bullet points)

     3. Recommended Decisions & Next Steps



System Constraints:

- Minimalist, high-end corporate UI (sleek slate/navy/dark-grey palette).

- No fluff or overly conversational filler—Lana delivers direct, actionable intelligence.

- Include subtle loading/processing indicators when generating outputs to simulate active processing.
